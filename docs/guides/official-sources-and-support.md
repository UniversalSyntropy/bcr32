## Before you contact support

1. **Update the software:** install the newest Control Tribe app and the newest firmware that it offers.
2. **Note the facts:** write down the firmware version (Global Settings, B11) and the operating system. Add the Control Tribe version and the connection (USB or DIN).
3. **Back up:** export your presets and patterns before you try any fix. A repair or a reset can erase them.
4. **Describe the fault:** say what you did, what you expected and what happened. Add a photo or a short video if it helps.
5. **Use the model link:** open the BCR32 support link above, so the request carries the model and product code.

> **Warning:** Do not send passwords, licence keys or personal data in a public post. Do not post a serial number in public.
