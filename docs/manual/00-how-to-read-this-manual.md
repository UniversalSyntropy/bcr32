# 0. How to read this manual

- **Control IDs** use the official manual's callout numbers: `B<n>` (button), `E<n>` (encoder), `SEL` (select encoder, 58), `DISP` (display, 57), `J<n>` (rear jack).
- **Step to encoder:** step k is `E(24+k)`. Step 1 is E25, step 32 is E56. "The nth encoder" in the official manual means E(24+n).
- **Panel label to ID:** the small number printed above each of the 16 parameter buttons (1–16) is not the ID. ID = label + 4, so panel "1 PITCH" is B5 and panel "16 DIRECTION" is B20.
- **Action notation:** `hold X + Y` means keep X down, then press or turn Y. `X ×3s` means hold X for three seconds. `turn E` and `push E` mean rotate and press an encoder. CW and CCW mean clockwise and counter-clockwise.
- **Mode first:** most controls change meaning with the mode, so each procedure starts by naming the mode ([Modes and menus](02-modes-and-menus.md#2-modes-and-menus-state-machine)).
- **New to the unit:** start with the [quick start](10-quick-lookup-how-do-i.md#101-quick-start-play-a-pattern-in-zaq-mode) in chapter 10.
