# local

Personal setup notes. Everything in this folder except this README is git-ignored.

Use it for facts that identify you or your setup: computer names, network details, DAW project names, unit serial numbers, test logs.

LLM agents read `local/SITE.md` first if it exists (see [CLAUDE.md](../CLAUDE.md)). A suggested layout:

| Section | Contents |
| --- | --- |
| Computers | Which computer the unit connects to, operating system, DAW version |
| Connections | Cables, MIDI and CV routing to other gear |
| Open issues | Problems under investigation and results so far |
